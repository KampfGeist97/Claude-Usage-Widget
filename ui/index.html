CLAUDE

Usage

Claude verbinden

Einmal in einer isolierten Claude-WebSession anmelden. Danach liest das Widget die Usage live im Hintergrund.

–

Einstellungen

Ein: beim Wiedereinblenden an der letzten Position. Aus: unten rechts über der Taskleiste des aktuellen Monitors.

Aus: bleibt als Always-on-top-Dashboard sichtbar. Ein: Klick außerhalb blendet es aus.

Die Claude-WebSession ist nur für dieses Widget und getrennt von Claude Desktop/anderen Browsern. Das Widget speichert den Session-Key nicht selbst; Chromium verwaltet die Session in seinem lokalen Profil.

Der verwendete Claude.ai-Usage-Endpunkt ist nicht als öffentliche Drittanbieter-API dokumentiert und kann sich ändern.
